# Phone app

This folder will hold one [Flutter](https://flutter.dev) app for Android and iPhone, with small Kotlin and Swift layers that call the Rust core through [UniFFI](https://github.com/mozilla/uniffi-rs).

The app isn't here yet. See [decision 0006](../docs/decisions/0006-flutter-phone-app.md) for the design and the rules it has to follow.
